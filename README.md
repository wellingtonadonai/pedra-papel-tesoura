# Pedra, Papel e Tesoura 🪨📄✂️

Jogo clássico "Pedra, Papel e Tesoura", desenvolvido com HTML, JavaScript e imagens para fins de prática e aprendizado em desenvolvimento front-end.

## 🎮 Funcionalidades

- Interface interativa com botões de escolha (pedra, papel ou tesoura)
- Jogada automática do computador
- Exibição do resultado da rodada
- Atualização da pontuação durante o jogo

## 🚀 Tecnologias utilizadas

- HTML
- JavaScript (manipulação de DOM e lógica do jogo)
- Imagens para representar as escolhas

## 💻 Como executar o projeto

1. Clone este repositório:
   ```bash
   git clone https://github.com/wellingtonadonai/pedra-papel-tesoura.git
   
Acesse a pasta do projeto: cd pedra-papel-tesoura

Abra o arquivo index.html em seu navegador.
